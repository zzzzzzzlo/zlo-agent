# Windows 验证记录

环境为 Windows 11（Build 26200，125% 缩放）、Node.js 24.15.0、Electron 43.4.1。使用独立测试配置目录，实际启动开发窗口和生产渲染器。

| 项目 | 结果 |
| --- | --- |
| 类型与生产构建 | `npm run typecheck` 和 `npm run build` 通过 |
| 便携程序 | 圆角版 Windows x64 EXE 实测启动，默认浅色的透明度、模糊与圆角参数生效，Mock 消息可发送，窗口可关闭。程序未签名 |
| 桌面窗口 | 验证最小化、最大化、还原和关闭。Win32 命中测试分别识别出标题栏拖动区、按钮客户区和右下角缩放区 |
| 窄窗口与 DPI | 在 125% 缩放将窗口调整为 680 × 520 DIP，检查了输入框、欢迎页、侧栏和活动栏的布局 |
| 会话和消息 | 验证新建、切换、重命名、删除、Enter 发送、Shift + Enter 换行、跨会话输出隔离和重载后恢复 |
| Mock 工具和状态 | 验证流式回复、工具详情、运行中、完成、取消和失败 |
| 外观和玻璃 | 验证两种主题、三档强度、SVG 位移滤镜和磨砂降级。通过独立后方测试窗口验证真实透景与磨砂 |
| 未接入入口 | 模型和附件按钮会显示状态提示 |

## 原生材质验证

在 Zlo Agent 窗口后方放置独立灰阶测试窗口，通过 Windows 屏幕合成采样。浅色背板在均衡档的着色不透明度由 64% 调为 60%，输入坞内的模糊由 3.52 px 调为 4.72 px。在后方放置一条硬边时，前景跨边界的灰度样本为 209、217、226、232。桌面模糊由 DWM 提供，输入坞与弹层使用 Liqui 的模糊和 SVG 位移滤镜。

在 125% 缩放下检查了 DWM 窗口圆角、标题栏命中和边缘缩放命中。界面外缘使用连续圆角，最大化贴齐屏幕，还原后恢复圆角。最小窗口内的输入框和聊天布局仍在可视宽度内。
