- 两项动画测试启动真实 Edge，渲染多个时间点。测试 Provider 检查 Pi 请求中的 JPEG 像素，再返回针对遮挡问题的编辑。重新渲染验证目标像素和动画采样。文字模型降级、图像尺寸与字节限制、本地资源和网络限制均有断言。
- 同一 Workspace 的独立只读 Worker 可并行。写入由任务范围和工作区冲突约束，Team 可在等待时让获准 Worker 编辑。回归验证子节点不能扩大范围、访问级别、工具和预算。停止并恢复后使用原 Team Session，同目标与授权的 Worker 复用原节点。
- Worker 通过真实 Shell 执行已批准的测试命令。Root 不能使用 Worker 的进程句柄。真实 Edge 测试验证 Root 和 Worker 的浏览器会话隔离，Worker 可截图和读取自己获准的文件。工具调用和资源状态通过 Host 结算。
- Java 交付用例通过 Pi Faux 编排文件与 Shell 工具。本机 JDK 25.0.4 实际编译并执行四项行为断言，随后检查进程退出码、输出和持久化回执。WorkBuddy 复核了该用例的编译产物与运行链路。工作区每次新建，编译成功后才执行测试。
- Pi 请求验证覆盖可信 AGENTS.md、Skill 清单和按需加载、撤销后拒绝、原生顺序工具执行、DeepSeek 推理参数、输出限额和失败重试。模型预算覆盖子节点及父级额度、不确定用量核销和重启后的预留恢复。
